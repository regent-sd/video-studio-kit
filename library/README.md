# Footage Log

A record of what's in every raw clip, down to the second, and a tracker of every finished video: what it used, and whether it's posted. Search both in Video Review (**Footage** and **Videos** tabs at http://127.0.0.1:8765/library), or open the CSVs in `<content>/Footage Log/` in any spreadsheet.

This folder also holds the **build records** every builder keeps, and the **finishing step** that puts an export in its shoot.

## What's in this folder

| File | What it is |
|---|---|
| `footage.py` | `scan`, `prep`, `index`, `check` (see its docstring): transcripts, frame sheets, the index, the tracker |
| `usage.py` | Works out which raw seconds each finished video used, from build records and lines added by hand, into `<content>/Footage Log/usage.json` |
| `buildrecord.py` | Build records: what a render shows over each stretch, the raw seconds it used, its song and its separate sound tracks. Every builder calls it at the end of a render. |
| `finish.py` | Puts a finished file in its shoot (never over an existing one), writes its sound and effects maps from the build record, then runs `usage.py` and `footage.py index` |

## Folder rule (your content folder)

One folder per shoot, named `YYYY-MM-DD Title` by the first day filmed. When several projects are filmed on one day, each gets its own dated folder.

```
2026-03-14 Kitchen Remodel/
  Raw/Camera/          camera originals from the main camera
  Raw/POV/             glasses or a head-mounted camera
  Raw/Phone/           phone clips
  Raw/Screen/          screen recordings
  Raw/Photos/          stills and screenshots
  Finished/Instagram Reels/   final exports, with their cover, caption and .srt beside them
  Finished/YouTube/
  Style Tests/         new looks and versions waiting for your OK
  Older Versions/      versions a newer export replaced (kept for their review notes)
```

Any subfolder of `Raw/` works: its name becomes the clip's **camera** in the log and the Footage tab's camera filter. Raw files are camera originals: never edit or rename them.

A finished video's posting status lives in the tracker, not in its folder. `Footage Log/` holds the index, the tracker, the CSVs and the build registry. `_To Delete/` holds broken or duplicate files for you to clear.

## Files in `<content>/Footage Log/`

| File | What it is |
|---|---|
| `footage-log.json` | Every log card in one file, plus `used_in` (generated: don't edit) |
| `Footage Log.csv` | One row per moment, for a spreadsheet or a phone (generated) |
| `video-tracker.json` | Every finished video, style test and older version: status, posted date and link, clips used. Status, dates, links, titles, brand, style and notes are kept as set; everything else is refreshed. |
| `Video Tracker.csv` | The tracker as a sheet (generated) |
| `usage.json` | Raw seconds each video used (generated by `usage.py`) |
| `usage-added.json` | Raw seconds added by hand (`usage.py add` / `same`) for videos whose builder keeps no record |
| `builds.jsonl` | The build registry: one line per render and per file `finish.py` placed. The map tools search it by picture. |
| `effects-applied.json` | Written by `effects/fx.py apply`: what each effects export was made from |

Next to each raw clip:

| File | What it is |
|---|---|
| `<clip>.log.json` | The log card. Claude writes it; your corrections go here too. |
| `<clip>.words.txt` | The clip's transcript (`start-end word` per line). Video Review reads it. |

`~/.cache/footage-log/` holds the frame sheets and briefs used while logging. Safe to delete.

## Routine: "log new footage"

1. Put the clips in the shoot's `Raw/<camera>/` folders (make the shoot folder if it's new).
2. `.venv/bin/python library/footage.py prep`: transcribes each new clip with whisper.cpp, makes frame sheets with time labels and writes a brief per clip.
3. For each clip, read `~/.cache/footage-log/<shoot>__<clip>/brief.md` and look at every sheet it lists, then write `<clip>.log.json` in the format below. For many clips, split shoots across subagents.
4. `.venv/bin/python library/footage.py check`: lists missing or broken cards, moments that leave gaps, overlap or run past the end, and people it doesn't know. Fix them.
5. `.venv/bin/python library/usage.py && .venv/bin/python library/footage.py index`: refreshes "used in", the tracker and the CSVs. Run this after every new export too (`finish.py` runs both). `footage.py index` also makes any sound or effects map a video is missing, from its build record, and prints a short list of any it couldn't, with the reason; a video that failed isn't tried again until its file changes.
6. Say what was logged and anything flagged (people who'd need permission, bad audio, a clip that's mostly unusable).

## Log card format

```json
{
  "clip": "C0041.MP4",
  "shoot": "2026-03-14 Kitchen Remodel",
  "brand": "example-brand",
  "camera": "Camera",
  "recorded": "2026-03-14T10:12:08",
  "duration": 241.3,
  "orientation": "horizontal",
  "summary": "Talking to camera at the kitchen island about why the old layout didn't work, then walking through the new one.",
  "location": "kitchen",
  "people": ["owner"],
  "speech": "to camera, clear voice, whole clip",
  "audio_notes": "",
  "quality": 4,
  "flags": [],
  "tags": ["talking-to-camera", "before-after", "kitchen"],
  "moments": [
    {
      "start": 9.7, "end": 13.9,
      "what": "Seated at the island, says the old kitchen never worked",
      "said": "This kitchen never worked for us…",
      "people": ["owner"],
      "tags": ["talking-to-camera", "hook"],
      "use_for": ["hook", "story opener"],
      "flags": [],
      "best_still": 11.0
    }
  ],
  "logged": "2026-03-14 by Claude",
  "reviewed": false
}
```

- **brand:** the brand's folder name in `brands/` (`example-brand` until you add your own).
- **camera, recorded, duration, orientation:** copy them from the brief. `camera` is the `Raw/` subfolder. `recorded` is local time (`timezone` in `studio.json`, else this Mac's), or `null` if the file doesn't say.
- **Times** are seconds into the clip, from the sheet labels and the transcript. Moments run back to back and cover the whole clip, at most about 30 s each for action and longer for one continuous talk. Split wherever the action or the topic changes. A long static take can use longer moments, one per step or set.
- **what:** what you can see, in plain words. **said:** the key line, cleaned up from the transcript (fix obvious mishearings from context, and spell names and products the way the brand does). Leave it empty when nobody speaks.
- **people:** your first name (`owner` in `studio.json`; write `owner` if it isn't set), a name from `people` in `studio.json` (people who often appear and have agreed to be filmed), or a role: `staff`, `customer`, `guest`, `child`. **Never guess a name from a face.** If you film yourself with a head-mounted camera, your hands in frame count as you. `footage.py check` flags any other name.
- **tags:** lowercase, hyphenated. Kinds of shot: `talking-to-camera`, `voiceover`, `pov`, `b-roll`, `close-up`, `wide`, `process`, `reveal`, `reaction`, `tasting`, `establishing`, `timelapse-able`, `slow-motion` (high-fps clips), `selfie`, `screen`. Then the subject: the products, steps and places in the shot (`dough`, `pour`, `before-after`, `kitchen`, `workbench`…). Reuse tags that are already in the log; they're the Footage tab's filters.
- **use_for:** what an editor could use it for: `hook`, `b-roll`, `cover-still`, `story`, `tip`, `ending`, `transition`, `ad`.
- **flags:** `shaky`, `dark`, `blown-out`, `out-of-focus`, `hdr-flat`, `room-hum`, `background-music` (music playing in the room), `wind`, `muffled`, `loud-machine`, `hat-brim` (a cap brim or glasses frame in shot), `brand-on-screen` (another company's product or logo), `needs-permission` (a recognisable face of someone who hasn't agreed), `private` (family, kids, a screen with personal details), `keep-out` (something on the brand's keep-out list, `brands/<brand>/brand.json`).
- **quality:** 1 (unusable) to 5 (great), for the clip as a whole.
- **best_still:** a time with a clean frame for a cover or thumbnail, if there is one.
- Never record GPS or addresses from the file's metadata.
- `used_in` is added by `footage.py index`; don't write it on the card.

## The video tracker

`footage.py index` lists every video in a shoot's `Finished/`, `Style Tests/` and `Older Versions/` folders. A new one starts as **in review** (style tests), **ready to post** (finished) or **superseded** (older versions). Statuses:

| Status | Means |
|---|---|
| `in review` | waiting for you to watch it |
| `ready to post` | approved, not posted yet |
| `scheduled` | set to go out later |
| `posted` | live, with the date and the link |
| `shelved` | kept, but not going to be posted |
| `superseded` | a newer version replaced it |

Change them in the Videos tab, or tell Claude "mark <video> posted". Only `status`, `posted_on`, `post_url`, `title`, `brand`, `style`, `platform` and `notes` are kept by hand; `footage.py index` refreshes the rest. A video's brand starts as the brand most of its shoot's log cards name, else `default_brand`.

## Build records (for builders)

Every builder keeps a record of each render, so the finished video gets its sound and effects rows in Video Review and the Footage Log knows which raw seconds it used. Standard library only; nothing in it can stop or change a render (a problem prints one line starting `[build record]`).

```python
import sys; sys.path.insert(0, "<kit>/library")
import buildrecord as BR

rec = BR.Record("my_builder.py", inputs=[spec_path])
rec.layout(0.0, 3.2, "fastcut", "split", detail="hook panel")   # a layout, by the builder's own name (BR.VOCAB)
rec.graphic({"type": "hook", "start": 0.0, "end": 2.5, "text": "The reveal"})
rec.effect("spotlight", 6.37, 8.89)                             # a library effect
rec.block(9.0, 11.0, "Tag", detail="“Fresh”")                   # anything else, by its Glossary name
rec.tags(12.0, 15.0, [(0.4, "Fresh"), (1.2, "Local")])         # a scene's pop-in tags as one block
rec.used(clip_path, 41.2, 44.6)                                 # raw clip seconds this render shows
rec.song(music_path)                                            # or rec.song(music_path, title="Title (Artist)")
rec.track("voice", [(voice_wav, 1.0)])                          # each sound track, at its level in the mix
rec.track("music", [(music_wav, 0.3)])
rec.save(render_path)                                           # after the render
```

| Function | What it does |
|---|---|
| `Record(builder, inputs=())` | Starts a record. `builder` is the script's name; `inputs` the spec or files it read. |
| `.layout(t0, t1, vocab, key, detail="")` | A scene layout by the builder's own name. `vocab` is a table in `BR.VOCAB` (`fastcut`, `talking-head`, `hands-on`, `shots`, `graphics`); an unknown name still makes a block, labelled with the name, and a note. Back-to-back stretches of the same layout join. |
| `.graphic(event)` | A graphic dict (`type`, `start`, `end`, `text`/`title`/`lines`) from `VOCAB["graphics"]`. |
| `.effect(name, t0, t1)` | A library effect (its catalog name). |
| `.block(t0, t1, label, entry=None, detail="", key="", group="graphic")` | Anything else on screen. `entry` is its Glossary name, if it has one. |
| `.tags(t0, t1, [(seconds into the scene, text)])` | One scene's tags as one block. |
| `.used(clip, t0, t1, approx=False)` | The raw clip and the seconds of it this render shows (clip seconds, not render seconds). Call it once per piece. |
| `.song(path, title=None)` | The song. Without `title`, its name comes from `music.json` (`{"<file name>": "Title (Artist)"}`) in the song's folder or the music library, else the tidied file name. |
| `.track(kind, [(file, level)], name=None)` | A sound track: the files that add up to it, each at its level in the mix. `kind`: `voice`, `voice_nat` (voice and footage sound in one), `mix` (everything but the effects), `music`, `nat` (footage sound). |
| `.track_cmd(kind, ffmpeg_args, name=None)` | A track made by an ffmpeg command whose filter graph ends in `[out]` (for builders that mix in a temporary folder). |
| `.tracks_from(other_render)` | Reuse another render's tracks and song (a picture-only re-render). |
| `.save(render, maps=True, keep_in=None)` | Writes `<render>.build.json` and `<render>.tracks/` (small mono 8 kHz copies) beside the render, or in `keep_in`, and a line in the build registry. When the render is already in the content folder it also writes both maps. |
| `register_vocab(name, table, plain=None)` | Adds a builder's own layout names: `{key: (label, glossary entry or None, detail) or None}`. |
| `find_records(picture_md5)`, `stream_md5(file, "v"/"a")`, `make_maps(video)`, `check_maps(root, files)`, `note_placed(dest, src)` | Used by `finish.py`, `soundmap.py`, `effectsmap.py`, `usage.py` and `footage.py`. |

The registry is `<content>/Footage Log/builds.jsonl` (or `~/.cache/video-studio/builds.jsonl` while the content folder isn't there). `VS_BUILD_REGISTRY` (a file) and `VS_CONTENT_ROOT` (a folder) point it elsewhere for tests.

## Finishing an export

```bash
.venv/bin/python -I library/finish.py WORK/NAME_sfx.mp4 "<shoot>/Style Tests/<Name>-v1.mp4"
.venv/bin/python -I library/finish.py --maps "<content>/<shoot>/Style Tests/<Name>-v1.mp4"   # maps only (--replace to redo)
```

It refuses a name that's already there (a new version always gets a new name), refuses `Raw/` folders, copies the file in safely, notes which render it came from, writes the sound map and the effects map from the build record, then runs `usage.py` and `footage.py index`. If a map can't be made it says why in one line, and the video stays where it was put. `--no-tracker` skips the last step.

## Raw seconds used (`usage.py`)

`usage.py` gives each video the raw seconds its build record lists (`rec.used`): the render's own name, every file `finish.py` placed from it, and any video in a shoot with the same picture. For a video made without a record (edited in another app, say), add the seconds by hand:

```bash
.venv/bin/python library/usage.py add "Kitchen-Reveal-v1.mp4" C0041.MP4 9.7 13.9
.venv/bin/python library/usage.py same "Kitchen-Reveal-Short-v1.mp4" "Kitchen-Reveal-v1.mp4"   # a cut-down of it
.venv/bin/python library/usage.py show "Kitchen-Reveal-v1.mp4"
```

A builder that keeps no record can call `usage.register("Out-v1.mp4", [(clip, from, to), …], built_by="my_builder.py")`.
