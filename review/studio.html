          Glossary

          Every named thing in the studio, in one place. It's built from the files that define each one, so it's always current. Say a name to Claude and it means exactly this.

          Classroom

          Reels saved for how they're edited: a look, a cut, an effect, a sound. Claude reads the ones a project card names before planning an edit. Reels saved for what they say are in Ideas. To add one here, tell Claude add this to the classroom: <link>

          Ideas

          Reels saved for what they say, not how they're cut: what to make, how to plan it, how to shoot it, how to work. They aren't editing references, so Claude doesn't use them when planning an edit. To add one, tell Claude add this to ideas: <link>

          What to say to Claude

          Click any phrase to copy it.

          Effect commands

          Each effect has its own command. Type it with a video and a word or time, for example /spotlight <video> at "<word>". The Glossary shows what each one looks like.
