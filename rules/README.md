# House rules

`house-rules.md` is the list of standing rules Claude follows on every video, before any style or brand rule. It's yours: it's made at setup and only changes when you say so.

| File | What it is |
|---|---|
| `house-rules.md` | Your rules. Made at setup from one of the two files below. Not there yet? Run the setup (`START-HERE.md`). |
| `house-rules.starter.md` | The starter set: rules learned from many rounds of real editing notes, each with its reason. |
| `house-rules.blank.md` | A clean start with only the four rules the tools rely on. |

At setup Claude asks: **adopt the starter rules, go through them one by one, or start clean?** Going through them, you can keep, change or drop each rule.

Change them any time:

- "add a house rule: no music under talking-head reels"
- "drop the house rule about effects every 10–15 seconds"
- "show me the house rules"

Brand-specific rules (colours, what never goes on screen, how the brand sounds) go in that brand's folder instead (`brands/<brand>/`). How you like a story told, learned from your notes over time, goes in `guides/storytelling.md`.
