# House rules

The standing rules Claude follows on every video, before any style or brand rule. You started clean, so there are none yet besides the few the tools need to work safely (below).

Add one any time: say **"add a house rule: …"**. Claude adds it under the right heading with today's date. When a note you leave on a video says how you like things in general, Claude offers to add it here.

## Always on (the tools rely on these)

- **Never overwrite a reviewed file.** A fix is always a new version (v2, v3…).
- **Raw footage is never edited.** Camera originals in a shoot's `Raw/` folder stay as they are.
- **Flag anything Claude wrote** (titles, labels, jokes, explainer text) before you post it.
- **A plan before a build** for any new video.
