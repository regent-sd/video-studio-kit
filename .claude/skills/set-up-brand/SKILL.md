# Set up a brand

Follow `setup/BRAND-SETUP.md` ("For Claude: how to run the interview"). Use `brands/example-brand/` as the template and keep every key. Never invent facts about the brand: leave a field empty or ask.

To change an existing brand, read its three files first, change only what they ask, and show a new preview card.
